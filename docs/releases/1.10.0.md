## 新增

- 管理后台新增「实时路由」，显示进行中的请求从访问密钥、虚拟模型到实际上游的流向。可按节点筛选，查看等待、接收、输出与切换阶段，以及近期结束的请求，并打开对应使用记录。
- 供应商模板新增 ModelScope，自动填入 Chat Completions、Responses 和 Messages 端点。

## 改进

- 实时路由在高并发时按路径聚合连线，可按需显示已启用的空闲节点。流式请求在写出有效内容后才显示「输出中」，输出失败时仍可追踪最后命中的上游。
- 整理部署、开发与 API 示例，补充日志保留和延迟统计的实际口径，并记录当前实现与设计要求的差距。

## 升级说明

- 升级时可沿用现有数据目录和配置。实时路由收集当前进程的请求，重启后从新请求开始显示，历史记录仍可在「使用记录」中查看。
