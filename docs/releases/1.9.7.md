## 新增

- 增加路由预演，可按入站协议、流式、工具、并行工具和推理强度查看候选及密钥跳过原因。请求详情保存当时的路由快照与选择事件，上游健康页展示当前进程的候选冷却和探测状态。
- 增加兼容性验证，可指定候选、上游协议、入站协议及 SSE，验证文本、连续两轮工具和并行工具场景。每个模型保留最近 20 次验证结果，并关联实际上游和请求记录。
- 使用记录增加状态、供应商、虚拟模型、真实模型及入站/上游协议筛选；上游筛选条件匹配同一次尝试，包含失败后切换的路径。
- 请求详情增加 JSON 字段转换差异及可编辑正文的调试重放。重放使用当前配置和凭据，沿用原访问密钥身份，生成新记录并关联原请求。
- OAuth 账号支持原位重新登录，校验原用户及工作区或项目后替换凭据，保留账号 ID、历史关联和管理员启停状态。账号展开区展示最近上游返回的额度与限流信号、观测时间和来源请求。
- 增加可选会话粘性，通过 `--session-affinity` 开启后，按客户端 `X-Session-ID` 在同一候选内优先复用上次成功的密钥。绑定按访问密钥和候选配置版本隔离，不改变候选优先级或工具历史约束。
- 使用记录页增加存储管理，展示数据库、WAL、可复用空间、保留期和最近清理结果；支持按时间范围预览、清空载荷或永久删除记录及上游尝试。

## 修复

- 修复 Chat Completions 与 Responses 跨协议转换时将未指定的 `parallel_tool_calls` 补为 `false` 的问题，保留未指定与显式开关的区别。Messages 的并行控制转换仍有已知差距。

## 升级说明

- 升级前停止旧进程，保留原数据目录；首次启动自动创建新增的诊断、验证、额度观测和维护记录表。旧请求没有路由快照。
- 会话粘性默认关闭，绑定在进程重启后清空；启用后需要客户端明确发送会话头。
- 兼容性验证和调试重放会真实调用上游，最长两分钟。测试通过表示当时配置下对应场景可用，不代表所有模型、协议字段或客户端功能兼容。
- 日志清理跳过进行中的请求和尝试，独立保留 Antigravity 工具历史；分批提交后无法撤销，删除数据后的空间供 SQLite 复用，文件通常不会立即缩小。
- 额度信息来自上游响应，缺少信号时显示未知，不从本地 Token 用量推算剩余额度。
