## 改进

- 全面重做管理后台，迁移至 shadcn/ui，采用中性灰、黑白主操作和少量橙色点缀，统一浅色、深色及跟随系统外观。
- 精简导航、登录和各页布局，移除背景网格、噪点与宣传区域；使用记录直接展示筛选条件和紧凑表格，不再占用首屏展示配置数量。
- 请求详情改为宽抽屉，左侧按调用过程选择入站请求、上游尝试和客户端响应，右侧查看元数据与载荷；保留凭据遮罩、JSON 树、格式化、原文及 SSE 聚合查看。
- 供应商和模型路由改为独立新增、编辑页，支持直接访问与刷新，并在离开未保存修改时确认；模型候选采用左侧顺序列表、右侧配置编辑，支持候选及协议入口排序。
- 供应商、模型路由和访问密钥列表在 URL 中保留筛选与分页；表格提供固定表头和区域内滚动，健康页分别展示管理员启停与运行状态。
- 普通 API Key 和 Antigravity 供应商的真实模型目录改为点击「拉取模型」后加载，避免打开编辑页时自动请求上游。
- 更新性能监控、用量统计、上游健康、访问密钥及 OAuth 登录界面，并同步操作说明与界面截图。

## 升级说明

- 替换程序或更新镜像后，刷新浏览器加载新版管理后台。已有供应商、模型路由、访问密钥及日志继续使用，无需重新配置。
- 新增 OAuth 供应商时，先点击「创建并添加账号」，再登录或导入账号凭据。
